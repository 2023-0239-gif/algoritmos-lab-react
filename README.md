# Algoritmos Lab

Treinta ejercicios del documento «30 ejercicios C#» convertidos en mini aplicaciones web con React y Vite. Incluye buscador por nombre, tema o número y un menú dinámico para abrir cada ejercicio.

## Ejecutar en Windows

```bash
npm install
npm run dev
```

Abre la dirección local que muestra Vite en el navegador. Para generar la versión de entrega: `npm run build`.

## Contenido

Las mini aplicaciones aparecen numeradas de forma continua del 1 al 30. Para no dejar huecos, los ejercicios originales 18–32 se muestran como aplicaciones 16–30; no se agregaron ejercicios inventados. Los enunciados se usaron como fuente principal cuando el código C# de ejemplo contenía errores o discrepancias.

La app se adapta a escritorio y móvil. Los resultados se calculan en el navegador y no se envían a ningún servidor.
